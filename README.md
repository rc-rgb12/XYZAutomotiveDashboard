# Automobile Sales & Recession Analytics

An interactive Python dashboard and analysis project exploring automobile sales performance across yearly and recession conditions.

## Project objective

The project examines automobile sales trends, vehicle-type performance, advertising expenditure, and the relationship between unemployment and sales. The dashboard provides two views: **Yearly Statistics** and **Recession Period Statistics**.

## Tools

- Python
- Pandas
- Plotly
- Dash

## Dashboard features

- Interactive report-type selection
- Year selection for annual analysis
- 2×2 responsive dashboard layout
- Recession-period sales trends
- Vehicle-type sales comparisons
- Advertising expenditure breakdowns
- Sales patterns across unemployment rates

## Run locally

```bash
pip install -r requirements.txt
python dashboard.py
```

Open the local address printed in the terminal, usually `http://127.0.0.1:8050/`.

## Portfolio positioning

This is a portfolio case study using an educational automobile-sales dataset. It demonstrates data preparation, grouped analysis, interactive visualization, dashboard development, and analytical communication.
